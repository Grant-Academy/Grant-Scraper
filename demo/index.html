confidence 0.60 = min(model's own 0.60, rule score 0.70)

How confidence is decided

confidence = min(model's self-report, rule score). Rule score starts at 1.0. Below 0.70, or any serious rule, goes to review.

evidence not found verbatim in the chunk−0.50 · always review recipient text or amount text not in the chunk−0.30 year missing, or off the section's year−0.30 amount outside €50 – €5 000 000−0.30 name malformed in the source (cut off, garbled comma)−0.30 amount missing though the chunk lists euro amounts−0.20 type contradicts a legal-form marker (ry, säätiö, työryhmä, &)−0.15 name contains words not on the page−0.10

Three funders → several hundred

0:20
  1. Batch it. discover over the full funder list, extract --backend … headless. Tonight's cost: about a minute and a few cents per funder.
  2. Regression suite. The ground-truth funders run on every prompt change; a drop is a bug.
  3. Let the review reasons steer. The most frequent reason names the next rule or prompt line to fix.
  4. Known gaps, named. PDFs no index page links (Karjalan needs a search API), JS-rendered and 403 sites need the browser fallback, list-item headings (* ## Kuvataide 2026) and bare 2.000 amounts are not yet parsed.
  5. Import is one call. The rows already validate against the production schema; the importer checks the same five required fields.
